MEDIHUB sample QR codes

Open Scanner in MEDIHUB and scan these from the screen, or print this page. You can also save the PNG files and use Upload photo. Each sample can be received once (batch numbers must be unique).

1. Delivery of a medicine already in the catalog

Scanner finds Biogesic (QMC) by its barcode, then "Review and receive" opens Receive Stock with the batch number, quantity, dates, prices and supplier already filled in. Needs the demo data (barcode DEMO480100001).

What the code says
{"app":"MEDIHUB","medicine":"Biogesic","strength":"500mg","form":"Tablet","barcode":"DEMO480100001","branch":"QMC","batch":"TESTQR-BIO-001","qty":120,"mfg":"2026-08-01","exp":"2028-02-28","cost":38.5,"price":52,"supplier":"Supplier A (Demo)"}

2. Delivery of a medicine that is not in the catalog yet

No catalog medicine matches, so the scanner offers: receive it as an unlinked batch (name, barcode and details kept on the batch), or create the medicine from the code first. Link it later from Batches.

What the code says
{"app":"MEDIHUB","medicine":"Test Vitamin D3","strength":"1000IU","form":"Softgel","category":"Vitamins & Supplements","unit":"bottle","barcode":"TESTD3-0001","branch":"MT Carmel","batch":"TESTQR-D3-001","qty":60,"mfg":"2026-09-15","exp":"2028-05-31","cost":150,"price":199}

3. A manufacturer GS1 pack code

Reads the barcode (GTIN), expiry date, lot and quantity from the standard pack code, then asks which branch and medicine. The rest of the form is left for you to fill in.

What the code says
(01)04800100000011(17)281231(10)TESTQR-GS1-001(30)48

4. A code with a bad expiry date and quantity

Shows warnings ("Expiry date ... is not a valid date") and leaves those fields blank instead of accepting them. Good for checking error handling.

What the code says
{"app":"MEDIHUB","medicine":"Test Paracetamol","batch":"TESTQR-BAD-001","qty":-5,"exp":"2028-02-30","price":"abc","branch":"QMC"}
